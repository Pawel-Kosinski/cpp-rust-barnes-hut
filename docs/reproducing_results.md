# Reproducing the benchmark results

The v1.1.3 article uses raw process-level measurements generated by the
scripts below. The historical aggregate workbook is not used.

The repository contains both C++ and Rust implementations of the same two-dimensional Barnes-Hut benchmark workload.

## C++ build with CMake

From the repository root, run:

    cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
    cmake --build build --config Release

## Manual C++ build with Clang

Alternatively, the C++ files can be compiled manually with Clang:

    clang++ -O3 -std=c++17 cpp/generator.cpp -o bh_generator
    clang++ -O3 -std=c++17 cpp/bh_v1_direct.cpp -o bh_cpp_v1
    clang++ -O3 -std=c++17 cpp/bh_v2_pointer_tree.cpp -o bh_cpp_v2
    clang++ -O3 -std=c++17 cpp/bh_v3_vector_tree.cpp -o bh_cpp_v3
    clang++ -O3 -std=c++17 cpp/bh_v4_threaded_tree.cpp -o bh_cpp_v4
    clang++ -O3 -std=c++17 -fopenmp cpp/bh_v5_parallel_force.cpp -o bh_cpp_v5

## Rust build

From the repository root, run:

    cd nbody_rust
    cargo build --release --bins

## Requirements

The full workflow requires Bash, CMake 3.16 or newer, a C++17 compiler with
OpenMP, Rust/Cargo, Python 3, and Matplotlib. The large-scale experiment requires
substantial RAM and can take several hours.

Install the pinned plotting dependency with:

    python -m pip install -r requirements.txt

The Windows CI job verifies C++ and Rust builds. The complete scientific and
standalone-archive test workflow runs on Linux, which is the supported reference
environment for the publication scripts.

## Input-data generation

The C++ generator can create deterministic Plummer-distribution input files. The
default seed is 1337. It converts every raw 32-bit `std::mt19937` output `x` to
the unit interval with `float(double(x) / 4294967296.0)` rather than relying on
implementation-defined distribution-library behavior.

Example:

    bash scripts/generate_input.sh 1000 data/start_1000.txt 1337

Equivalent direct command after building the C++ targets:

    ./build/bh_generator 1000 data/start_1000.txt 1337

All variants consume the same explicit input and frame count. A selective run is:

    bash scripts/run_benchmarks.sh --input data/start_1000.txt --particles 1000 \
      --frames 5 --warmup-frames 1 --repeats 10 --theta 0.3 \
      --languages cpp,rust --variants v2,v3,v4,v5

Without `--output-dir`, the command creates a new UTC-dated directory below
`results/generated/`. It never overwrites an existing experiment. The summary
reports means and sample standard deviations across independent processes. Each
repeat runs all selected configurations once in a deterministically shuffled
order; use `--order-seed` to select and record another shuffle sequence.

If a long run is interrupted, repeat the identical command with `--resume` and
the same `--output-dir`. The runner validates the existing CSV schema, source
commit, protocol, selected configurations, and block positions before skipping
completed processes and executing only missing rows. It refuses to combine
results when any recorded setting differs.

## Manuscript figures

Run all publication experiments with one command:

    bash scripts/reproduce_all_figures.sh results/reproduced/$(date -u +%Y%m%dT%H%M%SZ)

The constituent scripts can also be run separately:

    output=results/reproduced/$(date -u +%Y%m%dT%H%M%SZ)
    bash scripts/reproduce_fig1.sh "$output/fig1"
    bash scripts/reproduce_fig2.sh "$output/fig2"
    bash scripts/reproduce_fig3.sh "$output/fig3"
    python scripts/plot_manuscript_figures.py \
      "$output" "$output/figures"

The scripts generate deterministic inputs, but large generated input files are
not versioned. Their seed, particle count, and SHA-256 hash are recorded in each
`environment.json` file.

## Numerical regression

Run the deterministic direct-versus-Barnes-Hut force comparison with:

    bash scripts/numerical_regression.sh

The test covers V2-V5 in C++ and Rust and reports global RMS and nearest-rank p95
relative force errors. It includes multiple theta values and particle counts,
coincident positions, unequal masses, and an explicit high-theta
self-interaction case. It also generates the same seeded input twice and checks
byte-for-byte equality. CI executes this test and an end-to-end runner test from
a standalone source archive with no `.git` directory.
